# 🍲 FoodBridge – Smart Food Distribution

## 📌 About the Project

FoodBridge is a web-based food distribution management system designed to help food banks distribute limited food supplies to community centers efficiently.

The application considers food availability, nutritional value, community demand, storage capacity, and social priorities to support better allocation decisions.

## 🎯 Objectives

- Reduce food wastage.
- Distribute available food efficiently.
- Prioritize nutritional requirements.
- Match food supplies with community-center demand.
- Improve social impact and food accessibility.

## ✨ Features

- **Dashboard:** View food availability, demand coverage, and impact statistics.
- **Food Inventory:** Monitor rice, wheat, pulses, and vegetables.
- **Community Centers:** View demand, storage capacity, and people supported.
- **Allocation Optimizer:** Choose between balanced, nutrition-first, and demand-coverage strategies.
- **Impact Report:** Review estimated people reached, nutrition scores, and waste avoided.
- **Responsive UI:** Adapt the interface to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Ensure the website code is saved as `index.html`.
4. Open `index.html` in your web browser.

No additional dependencies are required for the basic prototype.
